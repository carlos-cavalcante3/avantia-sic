# Commercial Intelligence ETL

**ETL project for the Commercial Intelligence system: extracts data from RD Station API, loads it into Supabase, and provides insights in Metabase.**

## 📂 Project Structure
```
etl_project/
├── data/
│   ├── raw/
│   └── processed/
├── logs/
├── src/
│   ├── extract.py
│   ├── transform.py
│   ├── load.py
│   └── pipeline.py
├── .env
├── .gitignore
├── README.md
├── requirements.txt
└── run.py
```

## ⚡ Features
- Extracts data from RD Station API  
- Transforms and cleans data for analysis  
- Loads data into Supabase 

## 🚀 Getting Started
1. Clone the repository
2. Create and activate a virtual environment
3. Install dependencies
4. Configure .env
5. Run the pipeline
